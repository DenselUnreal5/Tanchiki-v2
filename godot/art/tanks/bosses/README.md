# Текстуры боссов

Три модульных атласа, созданные встроенным imagegen:
- boss — Бронемонстр, бордовая броня и спаренные пушки.
- boss_rammer — Джаггернаут-Таран, охристая броня и отвал, без пушки.
- boss_chimera — Фантом-Химера, тёмная броня, кислотные резервуары и сопла.

PNG 1774×887 с прозрачностью. Левая половина — корпус, правая — башня/верхний модуль.
Ресурсы hull.tres и turret.tres выделяют половины атласа без изменения PNG.
В сценах каждого босса точки привязки настроены отдельно, размеры башен подогнаны
под корпус; башня поворачивается через Turret.rotation независимо от корпуса.
Нос техники направлен вверх; для игры с направлением вправо требуется +PI/2.

Откройте bosses_preview.tscn для просмотра трёх собранных машин.
Сцены используют Nearest. Для игрового размера подберите масштаб общего узла
по фактическому размеру босса; габариты коллизий должны остаться прежними.
Это статические текстуры без анимации гусениц и состояний повреждения.
Подключены через BossSprites в бою, главном меню и справочнике техники.
Башни используют исходные точки привязки и масштаб; только участок стволов
подогнан к существующей точке выстрела. Коллизии и баланс не изменяются.
Клон использует атлас Химеры с голубым голографическим оттенком.
Промпт каждого атласа сохранён рядом в prompt.txt.
