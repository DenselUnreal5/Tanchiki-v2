# military_props

12 текстур окружения. Атлас 1448×1086, RGBA, 4 столбца × 3 строки.
Каждый ресурс .tres выделяет объект из исходного PNG без изменения его прозрачности.
Порядок слева направо, сверху вниз:
1. fuel_barrel
2. fuel_barrel_burning
3. fuel_barrel_broken
4. generator_idle
5. generator_active
6. generator_broken
7. supply_crate
8. sandbags
9. concrete_barrier
10. base_bunker
11. tank_wreck
12. lamp_post

PNG создан встроенным imagegen; промпт сохранён в prompt.txt.
Используйте Nearest при масштабировании. Это отдельные объекты на прозрачном
фоне; они не являются бесшовными тайлами земли, дорог или реки.
Общий предпросмотр: res://art/environment/environment_attack_preview.tscn.
