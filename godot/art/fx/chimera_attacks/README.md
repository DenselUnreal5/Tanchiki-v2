# chimera_attacks

32 кадра атак босса. Атлас 1774×887 с прозрачностью, 8 столбцов × 4 строки.
Порядок строк:
1. acid_charge — 18 кадров/с, однократно.
2. acid_stream_loop — 20 кадров/с, цикл.
3. acid_splash — 20 кадров/с, однократно.
4. phase_shift — 16 кадров/с, однократно.

Ресурс SpriteFrames: chimera_attacks.tres. Используйте Nearest.
Направленные эффекты ориентированы вправо; корректировку направления удара
Тарана выполняет игровой рендер. Пиксельный шейдер отделяет полупрозрачные края
и скрывает стыки клеток. Некоторые частицы доходят до границ ячеек, поэтому
предпросмотр и игровая отрисовка используют один материал.

Создано встроенным imagegen; промпт — prompt.txt.
Предпросмотр: res://art/environment/environment_attack_preview.tscn.
