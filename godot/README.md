# Тянчики — Battle Tanks

Top-down танковый шутер на чистом Canvas. Однопользовательская игра против ботов и онлайн-режим через WebSocket. Без зависимостей и сборки — просто открой в браузере.

**Играть онлайн:** https://tanchiki-v2.onrender.com

## Возможности

- 🎮 Управление танком: WASD / стрелки — движение, мышь или Space — стрельба
- 🤖 Умные боты с поиском пути (A*)
- 🌦️ Динамическая погода
- 🎯 Множество видов оружия и перков
- 🏆 Достижения и ежедневные награды
- 🎨 Косметика и прокачка танка
- 🌐 Онлайн-режим по WebSocket (несколько игроков, CTF)
- 💾 Сохранение профиля (localStorage)

## Установка и запуск

```bash
# клонирование
git clone https://github.com/DenselUnreal5/Tanchiki-v2.git
cd Tanchiki-v2
```

### Локальный сервер

Игра требует HTTP-сервера (модули ES). На Windows:

```bash
start.cmd
```

или:

```bash
npm run serve
# python -m http.server 8000
```

Затем открой http://localhost:8000

### Онлайн-режим

Запусти WebSocket-сервер:

```bash
node server/ws.js
```

## Структура проекта

```
index.html        — точка входа
style.css         — стили
src/              — клиентская логика (модули ES)
  config.js       — константы и баланс
  game.js         — игровой цикл
  map.js          — генерация карты
  bot.js          — ИИ ботов
  net.js          — сетевой клиент
  ...             — оружие, перки, погода, HUD и т.д.
server/           — WebSocket-сервер
  ws.js           — запуск сервера
  game.js         — серверная логика онлайн-режима
tests/            — smoke-тесты и тестовые стенды
```

## Управление

| Клавиша | Действие |
|---------|----------|
| W A S D / стрелки | Движение танка |
| Мышь | Прицеливание |
| Space / ЛКМ | Стрельба |
| E / ПКМ | Мина |

## Технологии

- Vanilla JS (ES-модули), HTML5 Canvas, CSS
- Node.js + WebSocket для онлайн-режима
- Фиксированный шаг логики 60 Гц
