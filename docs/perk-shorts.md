# Короткие ролики про перки: первая пятёрка

Порядок задан по таблице открытия `Perks.UNLOCK_TABLE`:
1. `rapid_fire` — Скорострельность — уровень профиля 1.
2. `heavy_armor` — Усиленный корпус — уровень профиля 1.
3. `sprinter` — Спринтер — уровень профиля 1.
4. `regen` — Регенерация — уровень профиля 2.
5. `quick_vent` — Быстрый сброс (быстрая вентиляция) — уровень профиля 2.

Имена, полные описания, модификаторы и уровни выгружаются из игры в `perks.json`. Для коротких титров в `scripts/render_perk_shorts.py` используются отредактированные формулировки RU/EN/FR/ES. Перезарядка показана именно как сокращение интервала на 40%, а не как увеличение частоты на 40%. Быстрый сброс повышает порог выхода из перегрева с 30% до 55% нагрева, не ускоряя саму скорость охлаждения.

Каждый ролик длится 15 секунд: вертикальный H.264 1080×1920, 30 fps, yuv420p/BT.709, звук AAC. Четыре файла для одного перка имеют вшитые локализованные название, уровень открытия, подписи сравнения и субтитры. Дополнительно сохраняются UTF-8 SRT, оформленные ASS и чистый мастер MP4 с четырьмя выбираемыми дорожками субтитров. Для публикации в соцсетях удобнее файлы из языковых папок: их текст виден без настройки плеера.

Это постановочные сравнения в тренировочной сцене, не запись случайного матча. Две независимые симуляции используют реальный `World.step()` и `Tank`: без перка и с одним перком на «Универсале», без улучшений. Реальная скорость симуляции 60 тиков/с, запись 30 кадров/с, ускорение времени не применяется. Для брони показан одинаковый начальный обстрел; для скорости — повторяющиеся заезды; для регенерации — восстановление во время стрельбы; для сброса — повторные циклы охлаждения. Показатели берутся из состояния танков. Служебные профили создаются в отдельном XDG_DATA_HOME.

Музыкальная подложка синтезируется скриптом, без заимствованной коммерческой музыки; игровые звуки записывает Godot MovieWriter. Голосовой озвучки нет.

## Воспроизведение

Нужны Godot 4.7, FFmpeg с libx264/libass, Python с numpy/Pillow, DejaVu Sans и X11-дисплей, поддерживающий минимум 1080×1920 (например, Xvfb 1920×2160). Путь к Godot и DISPLAY передаются явно:

```bash
python3 scripts/render_perk_shorts.py --out /workspace/releases/perks-first-five --capture --godot /path/to/godot-4.7 --display :89 --jobs 2
python3 scripts/check_perk_shorts.py /workspace/releases/perks-first-five
```

Сцена: `res://tests/perk_short.tscn`. Для выборочного повторного захвата есть `--capture-ids=regen,sprinter`; без `--capture` заново создаются только языковые версии из записанных AVI. На время записи скрипт сохраняет и восстанавливает `godot/override.cfg`, чтобы MovieWriter получил вертикальное разрешение ещё до запуска сцены. Не запускайте одновременно редактор и захват в одном проекте.

Проверка сравнивает записанную покадровую телеметрию, уровни и модификаторы, формат/длительность 20 роликов, наличие звука и четыре дорожки субтитров в пяти мастерах. Генератор и сцена не меняют баланс и исключены из релизного экспорта через `tests/*`. Готовые ролики, субтитры, мастера и обложки хранятся в `marketing/perks-01-05/`. Исходные AVI и служебные профили остаются вне Git.

## Ролики 06–10: английский язык

Следующая пятёрка по `Perks.UNLOCK_TABLE`: Evasion и Scavenger (уровень 3), Nitro и Energy Shield (уровень 4), Double Shot (уровень 5). Готовые английские MP4 с вшитыми титрами, SRT/ASS, обложки и проверка находятся в `marketing/perks-06-10/`. Имена берутся из действующего английского перевода игры.

```bash
python3 scripts/render_perk_shorts.py --out /workspace/releases/perks-next-five --batch second --languages en --capture --godot /path/to/godot-4.7 --display :89 --jobs 2
python3 scripts/check_perk_shorts.py /workspace/releases/perks-next-five --batch second
```

Сцены показывают настоящие попадания и уклонения с фиксированным seed, восстановление по 3 HP после разрушения кирпича своими снарядами, активацию Nitro, поглощение 30 урона щитом и суммарный урон двойного залпа. Сравнение Nitro/щита повторяется отдельными дублями через 7 секунд со сбросом состояния; это не демонстрация перезарядки щита. Его 30-секундный цикл указан текстом. Кирпич для Scavenger появляется каждые 3 секунды. Базовая скорость симуляции сохранена; сырые AVI и изолированные профили остаются вне Git. Для этого набора создаётся только английская версия; чистые мастера с четырьмя языками не генерируются.

Для второй пятёрки тренировочная сцена фиксирует урон обычного снаряда по танкам на середине игрового диапазона, сохраняя множитель 60% для Double Shot. Это убирает случайные различия урона между двумя полосами. Уклонение по-прежнему случайное, с игровым шансом 15%; число реальных уклонений видно в ролике. Изменения ограничены тестовой сценой и не меняют игру.
