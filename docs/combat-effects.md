# Спецэффекты боя — 0.9.58

Обновление продолжает цепные молнии из 0.9.57. Все пункты аудита переведены
на общие пиксельные формы; спрайтовые выстрелы и статусы сохраняют отдельные
анимации. Координаты/толщина линий округляются, текстуры эффектов используют
Nearest, свечение состоит из дискретных полос яркости.

| Порядок аудита | Реализация |
| --- | --- |
| 1. Цепные разряды | `ElectricGlow`, связи между точками попадания, синее/жёлтое свечение (0.9.57) |
| 2. Кислотные лужи | `AcidPoolFx`: четыре неровных силуэта, палитра кислоты на танках, пузыри/брызги/пар |
| 3. Ударные волны | Пиксельные контуры, отдельные осколки; кристаллы льда, кислотные пузырьки, разряды EMP |
| 4. Горящие обломки | Ступенчатые языки огня с тёмной кромкой и светлой сердцевиной |
| 5. Щиты/защита появления | Отдельные сегменты бронеподобной оболочки, корпус остаётся виден |
| 6. Турбо/рывок | Огненные языки выхлопа и направленные пиксельные штрихи |
| 7. Дым/способности | Слоистые блоки дыма, ступенчатые дуги и частицы способностей |
| 8. Боссы | Пиксельные контуры зон тарана, вращения, перегрузки и подготовки кислотной струи |
| 9. Артиллерия/авиаудар | Пиксельные боеприпасы, хвосты и отметки зоны попадания |
| 10. Лазеры | Целочисленные линии и угловые скобки прицела |
| 11. Генераторы/клоны/маскировка | Ступенчатые ауры, ядра и целочисленные полосы голограммы |

## Организация

`godot/scripts/fx/pixel_fx.gd` содержит повторно используемые формы:
пятно, дугу, линию, полигон, огонь, сегменты щита, дым и прицел.
`WorldView` отвечает за порядок слоёв, отбор по видимой области и существующие
предупреждения. `GlowLayer` и вспышка в гараже используют одну текстуру свечения.
Шейдер `post_fx.gdshader` квантирует только добавленное свечение: исходное
изображение мира, HUD и цветокоррекция не пикселизируются повторно.

Вся анимация использует игровые тики: при паузе она неподвижна.
Для кислоты используются четыре кешированных изображения 64×64;
обычные пятна и свечение также кешируются, изображения не строятся каждый кадр.
Рисование не расходует игровой RNG, не меняет урон, радиусы, время жизни,
порядок выбора целей, столкновения или видимость скрытых танков.
Границы опасных зон продолжают использовать исходный радиус боевой механики.

Низкое качество убирает пар и часть пузырьков кислоты, осколки волн и ветви EMP;
основные сигналы опасности остаются. Уменьшение вспышек сохраняет читаемость
электрических разрядов и ослабляет их свечение.

## Проверки и просмотр

`tests/combat_fx_visual_check.tscn` требует графический дисплей и проверяет
26 вариантов: наличие изображения, стабильность при паузе, анимацию,
низкое качество, уменьшенные вспышки, сохранение RNG/HP/таймера кислоты,
исчезновение истёкшей лужи и ограниченный кеш.

Запуск с `-- --capture-fx` сохраняет таблицу вариантов в `user://combat_fx.png`.
Копия для просмотра: `screenshots/combat_fx.png`.
Дополнительные проверки: `shot_fx_check`, `tank_status_visual_check`,
`electric_chain_check`, `weather_visual_check`, `freeze_visual_check`.
