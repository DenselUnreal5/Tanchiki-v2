# UI/UX: варианты главного меню Iron Storm

Три концепта созданы встроенным imagegen для выбора визуального направления.
Это макеты: игровое меню пока не изменялось. Иллюстрации окружения и значения
профиля служат примерами, а не снимками текущего игрового состояния.

1. 01_field_headquarters.png — Полевой штаб: оливковая палитра, меню слева, большая кнопка боя.
2. 02_combat_terminal.png — Боевой терминал: стальные панели, танк в центре, условия боя справа.
3. 03_tactical_map.png — Тактическая карта: большая карта слева, выбор режима и снаряжения справа.

После выбора один стиль переносится в реальные компоненты Godot с точными
переводами, существующей навигацией и адаптацией под размеры окна.

## Поправки пользователя

Эти варианты слишком отличаются от настоящей графики игры. Следующий вариант должен опираться на реальный игровой рендер. Сохранить идею гаража с выбором танка и пушки. Способности выбираются только во время матча, не в гараже. Работа над UI отложена до исправления пустыни и разрушаемости окружения.
