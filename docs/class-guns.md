# Орудия под класс танка — 0.9.70

Выбранная пушка больше не подменяет родную башню класса башней Огнемётчика,
Химеры или Теслы. Игрок сохраняет башню, люк, оптику и точку крепления
своего корпуса; заменяется только ствол с функциональными деталями.

В TankSprites.GUN_FIT заданы пропорции для шести корпусов:
Универсал, Рядовой, Разведчик, Громила, Снайпер и Миномёт.
Разведчик получает узкий компактный вариант, Громила — толстый и короткий,
Снайпер — удлинённый, Миномёт — широкую короткую трубу. Для ледяной пушки
используется кожух с рёбрами, для кислоты — зелёные каналы, для огнемёта —
термоизоляция и сопло, для электричества — две направляющие.

Сборка выполняется один раз в исходном разрешении 64×64 и кэшируется по
корпусу и пушке. Исходные PNG не изменяются. Рисунок скина кэшируется с учётом
конкретной сборки; светящиеся и цветные детали пушки остаются читаемыми.
Нижняя часть родной башни совпадает с исходным спрайтом попиксельно.
Поворот и маски статусов работают через общий рендер WorldView, используемый
в бою, меню и гараже. Башни противников сохраняют авторские спрайты.

Урон, дальность, точка появления снаряда, коллизия и характеристики классов
не меняются. Стандартная пушка сохраняет исходный классовый спрайт.

```sh
godot --headless --path godot tests/class_guns_check.tscn
godot --path godot tests/tank_skins_preview.tscn -- --class-guns
```

Проверки охватывают все сочетания классов и пушек, все восемь скинов,
кэширование, сохранность башни и игровых параметров. Графическая сцена
сохраняет `user://class_guns.png` и проверяет различимость пушек.
