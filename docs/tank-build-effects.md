# Эффекты собранных билдов — 0.9.62

Танк получает эффект при полном наборе трёх перков билда. Завершение отмечается
коротким пиксельным импульсом и значком сборки (48 игровых тиков), затем остаётся
характерная анимация. Для неполного набора эффекта нет.

| Билд | Постоянный эффект |
| --- | --- |
| Владыка бури | Маленькое грозовое облако у кормы, сине-жёлтая молния |
| Лесной призрак | Приглушённые зелёные скобы и дрейфующие листья/частицы |
| Стальной таран | Бронепластины по краям носа, тёплые отблески и искры |
| Фантомный снайпер | Фиолетовый фантомный контур и прицел у конца ствола |
| Абсолютный ноль | Голубые кристаллы на бортах, фрагменты ледяной кромки |
| Чумной шквал | Зелёные пузырьки и испарения от бортовых портов |
| Инферно | Две огненные струи у гусениц, угольки и приглушённый свет |
| Громовой молот | Сине-жёлтые электрические дуги по бортам |

## Поведение

`TankBuildFx` вычисляет эффект по полным сборкам; `World` фиксирует только
локальные косметические времена их появления. Рисование не меняет это состояние,
игровой RNG, HP, таймеры статусов, характеристики или бонусы перков.
Повторные тики не перезапускают импульс. Потеря перка убирает эффект;
повторная сборка запускает новый импульс. Смерть скрывает эффекты,
возрождение с тем же билдом не повторяет старую вспышку.

Подложка находится под корпусом, основной эффект — вокруг корпуса и ствола;
эффекты отрицательных статусов накладываются сверху. Командные цвета сохраняются.
При нескольких сборках яркость слоёв уменьшается; одновременно показывается
только один временный значок. Низкое качество уменьшает число частиц,
уменьшенные вспышки ослабляют ореолы и импульс. Пауза останавливает анимацию.
Существующий фильтр видимости применяется до рисования танка и его эффектов.

## Сетевая игра

Хост передаёт в необязательном поле `extra.build_fx` только ID завершённых билдов
по `net_id` танка. Клиент восстанавливает косметику и локальную шкалу времени;
это не выдаёт клиенту перки и не изменяет боевые параметры. Неизвестные и повторные
ID не создают лишних эффектов. Пустой набор убирает эффект. Снимки старого формата
без этого поля по-прежнему принимаются; версия бинарного протокола не меняется.
Лесная маскировка учитывает авторитетный билд и на клиенте, скрывая также эффекты.

## Проверки и просмотр

- `tests/tank_build_fx_check.tscn`: все восемь сборок, частичный набор,
  завершение/потеря/повторная сборка, смерть/возрождение, косметический тик,
  передача ID в снимках, удалённое отображение без изменения бонусов.
- `tests/tank_build_visual_check.tscn`: требуется графический дисплей; различимость,
  анимация, пауза, низкое качество, уменьшенные вспышки, временный импульс,
  сохранение RNG/HP/статусов, скрытые враги, несколько билдов и отрицательные статусы.
- `tests/tank_build_preview.tscn`: анимированная галерея восьми эффектов;
  `-- --capture-builds` сохраняет снимки активации и постоянных эффектов в `user://`.
