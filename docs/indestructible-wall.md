# Неразрушаемый блок — 0.9.60

`Cfg.T_WALL` теперь использует `art/terrain/indestructible_wall.png`:
вид сверху на железобетонный блок со стальным ободом и угловыми креплениями.
Изображение создано imagegen для военного пиксельного стиля игры.
Полностью непрозрачный квадрат занимает всю клетку без зазоров.

Исходный PNG сохранён в полном разрешении; импорт Godot уменьшает его
до 32×32 (`process/size_limit=32`), как у существующих тайлов города.
`TerrainTextures.wall()` кеширует одну текстуру с фильтром Nearest.
Материал одинаков для всех локаций, включая неразрушимые стены внутри карты.

Основная отрисовка `WorldView`, запекание чанков `TileBakeView` и редактор карт
используют общий ресурс. При отсутствии ресурса остаётся прежний резервный
серый блок. Миникарта и схематический повтор смерти сохраняют цветовые обозначения.

Непроходимость, столкновения и иммунитет к урону не менялись.
`tests/wall_texture_check.tscn` проверяет ресурс, размер, непрозрачность,
кеширование, фильтрацию и сохранение стены после разных видов урона.
`tests/wall_texture_preview.tscn` показывает рамку и внутренние блоки на шести
локациях и сохраняет `user://wall_texture_preview.png`.
